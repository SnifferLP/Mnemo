# Screenshots

Public screenshots are intentionally not included in the repository yet. Add clean, current captures before publishing a release that advertises screenshots.

## Requirements

- Use a fresh **development** profile, not your personal production database.
- Create neutral sample sets and cards; do not use real personal study content.
- Do not show names, email addresses, API keys, provider keys, local paths, file names or notifications.
- Capture at the default 1440 × 920 window size in both light and dark mode where useful.
- Use PNG, optimize file size, and keep the interface at native scale.
- Do not include debug overlays, browser devtools or terminal windows.

## Suggested files

| File | View |
| --- | --- |
| `dashboard.png` | Dashboard with sample activity |
| `set-overview.png` | Study-set overview |
| `study.png` | Flashcards or writing mode |
| `statistics.png` | Statistics with sample history |
| `settings.png` | Appearance and typography settings |

Link the final files from the README screenshot section. Screenshots are project documentation, not generated build artifacts, so they may be committed once sanitized.
